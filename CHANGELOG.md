# Changelog

All notable changes to WorkPacer will be documented in this file.

## [0.1.0] - 2026-11-11

### Application
- Added the initial WorkPacer desktop application.
- Added work-session finish-time calculation based on start time and required work duration.

### Testing & Automation
- Added automated unit, application acceptance, and end-to-end tests.
- Added automated build support through `build.py`.
- Added self-contained Linux and Windows release generation through `release.py`.
- Added support for building the Windows standalone application from Linux.
- Added automated GitHub commit, version tagging, and push workflow through `push.py`.

### Documentation
- Added documentation for running, testing, building, releasing, and publishing WorkPacer.
